# 常见问题

## 安装与启动

**Q：需要安装数据库吗？**
不需要。EQS 用 Node.js 内置的 SQLite，数据就是一个 `data/eqs.db` 文件。

**Q：Node 版本要求？**
22.5 以上（需要内置 `node:sqlite`）。`node -v` 检查一下，版本不够请升级。

**Q：端口被占用怎么办？**
`PORT=9000 node server/index.js`（Windows：`set PORT=9000 && node server\index.js`）。

**Q：为什么没有 `npm install`？**
EQS 运行时零第三方依赖，`package.json` 的 `dependencies` 是空的，只有开发时的可选脚本。

## 备份与迁移

**Q：怎么备份最省事？**
压缩 `data/` 目录即可，数据库和上传文件都在里面。也可以用后台「导出备份」，或 `bash scripts/backup.sh`。

**Q：换服务器怎么做？**
老机器打包 `data/`，新机器解压到项目根目录，`bash scripts/start.sh` 启动，数据就回来了。

**Q：能迁移到 MySQL 吗？**
可以，替换 `server/lib/db.js` 的数据访问实现即可，SQL 都是标准语法。目前内置方案优先保证零依赖体验。

## 功能使用

**Q：表单发布了还能改吗？**
能。修改后已提交的答卷不受影响，但新增/删除题目会影响后续统计口径。

**Q：怎么让某些题只在特定条件下出现？**
设计器右侧「显示逻辑」→ 添加条件，选择依赖题目、运算符和比较值。多个条件是「且」关系。

**Q：考试怎么设正确答案和分数？**
在设计器选中题目，填「分值」，再给「正确答案」。不同题型的填法不一样：

- 单选 / 多选 / 判断 / 单选类：勾选项，或手写 `A,C`
- 排序题：**按正确顺序依次点选项**，点出来的序号就是标准顺序（顺序本身才是答案）
- 矩阵量表：**逐行选一列**，每行独立给答案
- 填空 / 简答：直接写标准答案，比对时忽略大小写和首尾空格

评分口径三个入口（交卷判分、交卷回顾、刷题判题）共用同一份实现，不会出现
「刷题判对、交卷判错」这种自相矛盾。

**Q：AI 生成需要付费接口吗？**
需要。支持任何 OpenAI Compatible 接口（DeepSeek、硅基流动、Qwen 等）。未配置时会自动降级为本地模板生成，功能不中断。

**Q：排序题 / 矩阵题的答案怎么填？**
排序题点选顺序即答案；矩阵题按行选列。题库和设计器里都有对应的专用编辑控件，
不用再手写逗号串——逗号串表达不了「第几位」和「哪一行」。

**Q：Excel 导入的矩阵题为什么没有行？**
需要在表格里多给一列「矩阵行」，一行一个评价对象。没有这一列，矩阵题插进题库后
只剩列选项、没有行，答题框渲染不出来。导出时会自动带上这一列。

**Q：附件下载后在哪？**
后台「答卷数据 → 打包附件」可下载整包 ZIP；单份答卷里的附件也可单独点开。

## 集成

**Q：外部系统怎么拉数据？**
`GET /api/sync/export?formId=1`，带会话 Cookie 或 API Key，返回全量答卷 JSON。

**Q：WebHook 怎么验签？**
请求头 `X-EQS-Signature` 是 `sha256=` + HMAC-SHA256(secret, 原始 body)，用配置里的密钥自行计算比对。

**Q：支持企业微信 / 钉钉通知吗？**
目前通过 WebHook 转发最省事：把企业微信机器人地址填进 WebHook 即可。

## 安全

**Q：默认密码是什么？**
`admin` / `admin123`。**上线前务必修改**（用户权限 → 改密，需要输入当前密码），或用环境变量 `EQS_ADMIN_PASSWORD` 在首次启动时指定。

**Q：陌生人能自己注册账号吗？**
默认不能。系统设置 → 站点 → 「允许自助注册」默认关闭，登录页也不会显示注册入口。
问卷系统的账号等于「能建卷、能看自己那份数据」，公开注册又没有审核环节，建议只在内部试用时打开。

**Q：API Key 是什么权限？**
只等于**签发它那个人**的权限。管理员在 系统设置 → API Key 里签发，签出来的 Key 就是管理员级；普通用户没有签发入口。
早期版本曾经把任何 Key 都当管理员，于是任何登录用户自助签一把就能导出整站数据——现在这条路已封。

**Q：改了密码，别的设备上的登录会怎样？**
立刻失效。改密码时服务端会记下时间点，此前签出去的所有会话全部作废，包括当前这条（会请你用新密码重新登录）。

**Q：暴力破解会被拦吗？**
会。同一账号 + IP 连续输错 8 次，锁 10 分钟；同一 IP 换着账号试，累计错 30 次也会锁整个来源（撞库的典型姿势）。
每次失败都会写进 系统设置 → 审计日志，包括「账号不存在」和「密码错误」的区别。

**Q：放在 Nginx 后面，日志里的 IP 全是 127.0.0.1？**
需要在 系统设置 → 站点 → 「客户端 IP 来源」里改成「信任代理头」并把代理层数填 1。
EQS 默认不信任 `X-Forwarded-For`：这个头是客户端自己发的，无条件采信等于让「每个 IP 限填一次」
和「登录失败锁号」两套限制失效——换个头就换了个计数器和一条新身份。
反过来说，用了 `deploy/nginx.conf` 那套配置却没打开这个开关，所有访客会被认成同一个 IP，
「每个 IP 限填一次」会变成「全站只能填一次」。这两件事必须一起改。

**Q：数据库文件被下载怎么办？**
`data/` 目录不在静态资源根目录内，Web 层无法直接访问。仍建议把它放在 Nginx 站点目录之外。

**Q：能限制只能内网访问吗？**
可以，用 Nginx `allow/deny` 或安全组限制来源 IP。
