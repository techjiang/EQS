# EQS 视觉设计说明

## Logo 理念

EQS 的图形由三部分组成：

1. **对话气泡**——问卷的本质是「提问与回答」，气泡是最直接的语义符号。
2. **三条递减的选项行**——点 + 线的组合既是表单里的单选项，也暗示从繁到简的收敛过程。
3. **右下角对勾徽章**——代表的不是「答对」，而是「收集完成、任务闭环」。这正是问卷、考试、刷题共用的一套心理奖赏。

配色取「信任蓝 → 创造紫」的斜向渐变（`#5b7cfa → #7b5bfa → #b45bfa`），对勾徽章用青色（`#22d3ee`）制造一点冷调亮点，避免整体过于甜腻。

### 无背景版本

所有 Logo 与图标均为**透明背景**：
- `assets/eqs-logo.svg` — 主 Logo，512×512，圆角留白，适合 App Icon、商店图标、宣传物料
- `assets/eqs-mark.svg` — 简化标记，64×64，用于侧边栏、favicon、小尺寸场景
- `assets/eqs-logo.png` / `eqs-mark-*.png` — 预渲染位图，覆盖 16 / 32 / 48 / 64 / 128 / 180 / 192 / 256 / 512
- `assets/favicon.ico` — 多尺寸图标容器

因为矢量、无底色、无外框，任何深浅背景、任何尺寸下都能直接用，不需要再切一张「深色版」。

## 设计系统

| Token | 值 | 用途 |
| --- | --- | --- |
| `--brand` | `#5b7cfa` | 主色，主按钮、链接、选中态 |
| `--brand-2` | `#8b5bfa` | 渐变的紫端 |
| `--brand-3` | `#22d3ee` | 强调点缀 |
| `--bg` | `#f6f7fb` / `#0d1020` | 页面底色（浅/深） |
| `--panel` | `#ffffff` / `#151a2e` | 卡片 |
| `--text` | `#141a2e` / `#eef1fa` | 主文本 |
| `--line` | `#e7eaf3` / `#242c46` | 分割线 |
| 圆角 | 10 / 16 / 22 px | 控件 / 卡片 / 弹窗 |
| 阴影 | 三级 | 微浮起 / 卡片 / 弹窗 |

**排版**：正文 14px，行高 1.6；标题字重 650，字距 -0.01em。中文优先 PingFang SC / 微软雅黑，数字与代码用等宽字体，保证表格对齐。

**间距**：以 4px 为基准，常用 6 / 8 / 12 / 14 / 16 / 18 / 22。

**动效**：150–250ms，`transform` 与 `opacity` 为主，避免触发布局重排。卡片 hover 上浮 1–2px，不夸张。

## 深色模式

深色不是把白色反转，而是重新配了一套对比度受控的层级：

- 底色 `#0d1020` 略偏蓝，与品牌紫蓝同色相，避免死黑
- 卡片 `#151a2e` 与底色仅差 8% 亮度，靠 1px `#242c46` 边框分层
- 主色保持 `#5b7cfa` 不变，但降低阴影强度，改用边框表达层级

图表颜色在深色下自动切换坐标轴与网格色（`#7c85a0` / `#242c46`），保证暗底可读。

## 交互原则

- **一屏一个主张**：工作台首屏只放统计数字与 6 个快捷入口，其余内容下沉一屏
- **危险操作二次确认**：删除、彻底删除全部走确认弹窗，回收中心兜底
- **自动保存**：设计器 1.5s 防抖静默保存，用户不必惦记「点保存」
- **空态有指引**：每处空列表都给下一步动作提示，而不是干巴巴的「暂无数据」

## 可访问性

- 语义化标签与 `label` 关联，键盘可完成全流程
- 控件最小点击区 30×30，移动端 38px 以上
- 主色与白底对比度 4.6:1，达到 WCAG AA
- 表单错误提示文案具体到字段名与原因
